# Python Essentials Lab Assignments

**Course:** Python Essentials  
**Course Code:** 23CSE1012  
**University:** MIT ADT University, Pune

## About
This repository contains Python programs for the 10 assignments in the Python Essentials laboratory manual.

## Assignments
1. Calculator Program
2. Earth and Moon Weight Calculator
3. Assignment List Manager
4. Secret Message Decoder
5. Student Grade Calculator
6. Password Strength Checker
7. Daily Calorie Calculator
8. Area of Different Shapes (function polymorphism)
9. File Reading Program
10. Data Visualization using Matplotlib

## Requirements
- Python 3
- Matplotlib (required for Assignment 10)

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Running an assignment
Open a terminal in this folder and run, for example:

```bash
python Assignment_01_Calculator.py
```

Each assignment is a separate Python file and can be run independently.

## Assignment 9
Keep `sample.txt` in the same folder when running Assignment 9, or enter the path to another text file.

## Note about Assignment 2
The lab manual refers to an external file named `Q01 challenge 1`, which was not included with the uploaded manual. The supplied program is a complete implementation of the stated Earth and Moon weight calculation task.
